{% if dhcp_mode == "dnsmasq-proxy" %}

dnsmasq proxy mode is active. This page shows the live proxy values and lets you edit them directly as simple fields.

  • Proxy-DHCP / PXE helper only -- the upstream/router DHCP server keeps issuing every ordinary client's lease and options
  • Every option below (router, NTP, domain, PXE/TFTP boot info, custom options) is delivered only through the supplemental ProxyDHCP/PXE exchange, to PXE/network-boot-aware clients. Ordinary clients never see them; their DNS, gateway, NTP, and domain settings come entirely from the upstream server.
  • No lease-time field: dnsmasq never issues a lease of its own in this mode, so a lease-time value would have no effect. Use Kea mode if you need LanCache NG to control lease time.
  • All fields below are plain text (IPs, a filename, a domain name); no JSON, no client-class syntax, no advanced parser tricks

{% elif dhcp_mode == "dnsmasq-relay" %} {# What: real DHCP relay to the upstream server #} {# Why: client broadcasts cannot reach upstream #} {# From: Issue #844 #}

dnsmasq relay mode is active. dnsmasq forwards every client's DHCP request to the upstream DHCP server and relays the reply back, so the upstream server owns the whole lease and all options.

  • Unlike ProxyDHCP mode, this is a real relay: it is useful when clients and the upstream DHCP server are on different network segments and the client broadcasts cannot reach the server directly.
  • Only two values are needed: this relay's own address on the client-facing network (stamped into the relayed request's giaddr, which the upstream server uses to pick the pool) and the upstream server address.
  • No subnet/DNS/PXE fields here -- a relay injects nothing of its own. Use ProxyDHCP mode for PXE option injection, or Kea mode to own leases here.
{{ }} {{ }}
{% elif dhcp_mode == "kea" %}

Kea mode is active. The configuration area below is visible and editable with direct fields for gateway, DNS, NTP, reservations, and subnet details.

  • Managed subnet values: gateway, pool, DNS servers, NTP servers, lease time, and domain-related DHCP options
  • Current Kea subnet editor preserves unmanaged option-data entries on save, but exposes only simple fields here
  • Static reservations and live leases are available below
{% else %}

DHCP management is disabled. The configuration area stays visible so the mode can be re-enabled later, but no active DHCP service is running.
