{# What: toggle that allows DNS updates without TSIG. Why: TSIG is required by default; this relaxes it. From: Issue #815 #}

DNS-Updates: TSIG-Pflicht lockern

PowerDNS verlangt bereits heute standardmäßig eine gültige TSIG-Signatur für DNS-Updates an die von diesem Projekt verwalteten Zonen (LAN/Reverse-Zonen), sobald ein echter DDNS-Schlüssel konfiguriert ist -- das ist praktisch immer der Fall. Diese Option schaltet diese Anforderung testweise gezielt ab: ist sie aktiv, akzeptiert PowerDNS auch unsignierte DNS-Updates von Hosts, die laut IP-Zulassungsliste grundsätzlich Updates senden dürfen. Das ist eine echte Verringerung der Sicherheit, kein rein kosmetischer Schalter -- nur aktivieren, wenn es einen konkreten Grund dafür gibt (z. B. ein Update-Client, der keine TSIG-Signatur unterstützt). Löst einen Neustart des dns-Containers aus (kein Live-Reload, PowerDNS liest diese Einstellung nur beim Start). Während dieses Neustarts beantworten beide DNS-Instanzen kurzzeitig keine Anfragen -- für alle Geräte im LAN, nicht nur für DNS-Updates, typischerweise wenige Sekunden pro Instanz. Nicht während laufender Downloads/Spiel-Updates umschalten, wenn das vermeidbar ist.
